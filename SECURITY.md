# Security and privacy

Codex Token Meter is designed to run locally. The web server binds only to
`127.0.0.1`, does not enable cross-origin access, and exposes aggregate usage
metadata rather than conversation content.

Do not publish `.codex` session files, `auth.json`, API keys, screenshots that
contain private paths, or other account data in issues.

If you find a vulnerability, avoid opening a public issue with exploit details.
Contact the repository owner privately and include the affected version,
platform, reproduction steps, and expected impact.
